## Datos clave del ESP32

1. Nucleo: Dual-core 32bit 
2. Frecuencia: 240MHz
3. Memoria SRAM: 8MB
4. Memoria FLASH: 16MB
5. Memoria ROM: 384KB
6. WIFI: 802.11 b/g/n
7. Bluetooth: Bluetooth 5
8. Voltaje: 5V
9. Temperatura: ~40 ~65
10. Dimensiones: 18.0 X 25.5 X 3.1
